Zero to God

Local Data and Deletion

Information for the current release of maan.z2g.game

Zero to God currently has no user accounts and does not store player profiles or game progress on a server operated by Aman Mann.

What is stored

The game may store progress, settings, and gameplay resource balances locally on your Android device.

How to delete local game data

  1. Open your Android device's Settings.
  2. Open Apps or App management.
  3. Select Zero to God.
  4. Open Storage.
  5. Select Clear storage or Clear data.

You can also remove local data by uninstalling the game. These actions may permanently erase progress because the current release does not include cloud saves.

Account deletion

No account-deletion request is needed because the current release does not allow account creation and does not maintain a server-side account.
