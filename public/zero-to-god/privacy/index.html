Zero to God

Privacy Policy

Effective date: 31 July 2026  ·  Package name: maan.z2g.game

This Privacy Policy explains how Zero to God, developed and published by Aman Mann, handles information when you use the game.

The current release is designed to work without user accounts, cloud saves, analytics, advertising SDKs, or in-app purchases. It does not ask for a name, email address, or other personal profile information.

Information we collect

The current release of Zero to God does not directly collect, transmit, sell, or share personal information or device information.

Local game data

The game may store progress, settings, resource balances, and similar gameplay information locally on your device. This information is used only to provide the game experience and is not uploaded to a server operated by Aman Mann.

Accounts and cloud services

Zero to God currently does not provide account registration, sign-in, cloud saving, or cross-device synchronisation.

Analytics and advertising

The current release does not use Firebase Analytics, Firebase Crashlytics, AdMob, or another third-party advertising or analytics service.

In-app purchases

The current release does not offer in-app purchases or paid subscriptions.

Permissions

Zero to God is not intended to request sensitive permissions such as contacts, precise location, microphone, camera, SMS, call logs, or storage access. Any standard operating-system access required to run the game is used only for core app functionality.

Children's privacy

The game is not specifically directed to children under 13. Because the current release does not knowingly collect personal information, it does not knowingly collect personal information from children.

Data retention and deletion

Because no account or server-side player profile is created, Aman Mann does not retain personal player data on a game server. Locally stored progress can be removed by clearing the app's storage in Android settings or uninstalling the game. See the Local Data and Deletion page for instructions.

Website hosting

This website is hosted using Cloudflare Pages. Cloudflare may process limited technical information necessary to deliver, secure, and operate the website according to Cloudflare's own policies. This website does not intentionally use advertising cookies or analytics scripts.

Future changes

If a future version adds advertising, analytics, accounts, cloud saves, purchases, or other data-processing features, this Privacy Policy and the Google Play Data safety declaration will be updated before or when those features are released.

Changes to this policy

This policy may be updated to reflect changes to the game or legal requirements. The revised policy will be posted on this page with a new effective date.
